# Работа с проектом на сервере

Памятка для разработчика, которому уже выдали доступ. Попросите у администратора
логин, адрес и отпечаток SSH-ключа сервера, имена проектов и, если нужен вход с
разных сетей, секретную ссылку доступа. В примерах ниже `anna`, `192.0.2.10` и
`shop` замените выданными значениями.

## Вход

```bash
ssh anna@192.0.2.10
sftp anna@192.0.2.10
```

Используйте личный SSH-ключ. Администратору отправьте только публичную часть (`.pub`).
Если закрытый ключ лежит под отдельным именем, укажите его через `-i путь_к_ключу`
перед логином. При первом входе сверьте отпечаток ключа сервера.
Если ваш IP уже разрешён, подключайтесь сразу. Из другой сети откройте выданную
ссылку и нажмите **«Открыть SSH»**. Открывайте её из той же сети и при том же
подключении к VPN, что и SSH. Срок доступа обычно составляет 24 часа.

## Файлы

```bash
go                     # показать доступные проекты или перейти в единственный
go shop                # перейти в /srv/projects/shop/web
ls -la                 # увидеть .env и другие скрытые файлы
mc                     # файловый менеджер, выход — F10
```

В SFTP-клиенте укажите протокол **SFTP**, порт **22**, свой логин и ключ.
Открывайте `/srv/projects/shop/web` напрямую. Там находятся код, `compose.yml`
и `.env`. Общий каталог `/srv/projects` может не показывать список папок.

## Docker

Если вам выдали право управлять контейнерами, эти команды запускаются через SSH.

```bash
project-compose shop ps
project-compose shop config --services
project-compose shop logs --tail 100 -f web
project-compose shop restart web
project-compose shop up -d
```

Подставьте имя сервиса из `config --services` вместо `web`. Для rootless проекта
вызывайте `project-compose` напрямую, без `sudo`. Если у вас доступ только к
файлам, запуск и перезапуск делает администратор.

## База данных

Если у проекта есть PostgreSQL, запустите эту команду на своём компьютере и оставьте
терминал открытым.

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:15432:127.0.0.1:5432 anna@192.0.2.10
```

В DBeaver, DataGrip или `psql` подключайтесь к `127.0.0.1:15432`.
Имя базы, роль и пароль берите из `DB_NAME`, `DB_USER`, `DB_PASSWORD` в
`.env` проекта или у администратора. Остановить туннель можно через Ctrl+C.
